# estudio.treso.cl

Web de Estudio Treso (TRESO SPA): inicio del estudio y páginas de Depth 40 (juego, soporte y privacidad), en español e inglés.

- `python3 build.py` regenera todas las páginas desde los textos del script.
- Publicada con GitHub Pages en el dominio `estudio.treso.cl` (archivo `CNAME`).

| Página | Español | English |
| --- | --- | --- |
| Estudio | `/` | `/en/` |
| Depth 40 | `/depth40/` | `/depth40/en/` |
| Soporte | `/depth40/soporte/` | `/depth40/support/` |
| Privacidad | `/depth40/privacidad/` | `/depth40/privacy/` |
