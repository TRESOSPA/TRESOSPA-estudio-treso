# estudio.treso.cl

Web de Estudio Treso (TRESO SPA): catálogo de todos los juegos y apps del estudio. Cada uno tiene su carpeta con su página, soporte y privacidad, en español e inglés.

Para agregar un juego o app: sumarlo a `CATALOG` en `build.py`, crear sus páginas (como Depth 40) y sus imágenes en `assets/`.

- `python3 build.py` regenera todas las páginas desde los textos del script.
- Publicada con GitHub Pages en el dominio `estudio.treso.cl` (archivo `CNAME`).
